Client-only starter kit

Code base gọn cho nhóm 4 người cùng phát triển.

Dự án dùng HTML, CSS, JavaScript module, Bootstrap 5 và Font Awesome. Không có backend; mọi tương tác chạy trực tiếp trên trình duyệt.

  2. Mỗi người nhận một module rõ trách nhiệm.
  3. Review qua UI, JS behavior và responsive layout.
